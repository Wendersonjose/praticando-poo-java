# ☕ Praticando POO com Java

Repositório de exercícios práticos desenvolvidos durante o curso de **Programação Orientada a Objetos com Java**, cobrindo os principais pilares do paradigma OO por meio de mini-projetos e simulações do mundo real.

---

## 📚 Sobre o projeto

Cada pacote representa um exercício ou módulo do curso, implementado de forma independente. O objetivo é consolidar os conceitos de POO na prática, evoluindo progressivamente ao longo das aulas.

---

## 🗂️ Estrutura de pacotes

| Pacote | Descrição |
|---|---|
| `exemplosHeranca` | Exemplos de herança, polimorfismo e sobrescrita |
| `agendaContatos` | CRUD simples de contatos |
| `bancoDigital` | Simulação de banco com contas e operações |
| `biblioteca` | Catálogo de livros |
| `cadastroValidacaoPreco` | Cadastro de produtos com validação de preço |
| `contaDigital` | Modelagem de conta digital |
| `controleSenha` | Autenticação e controle de usuário |
| `controleEstoque` | Gerenciamento de itens em estoque |
| `estoque` | Controle de estoque e produtos |
| `funcionarios` | Cadastro e dados de funcionários |
| `gerenciandoBiblioteca` | Gerenciamento de acervo (livros, e-books, mídias, revistas) |
| `identificandoEstudante` | Identificação de alunos e bolsistas |
| `oficina` | Simulação de oficina mecânica com veículos |
| `sistemaBancario` | Sistema bancário com operações e ações bancárias |
| `sistemaEscolar` | Escola com alunos, docentes e pessoas |
| `sistemaNotificacao` | Envio de notificações por e-mail, SMS e push |
| `sistemaPagamentos` | Formas de pagamento: boleto, cartão, pix |

---

## 🧠 Conceitos praticados

- Classes e Objetos
- Encapsulamento
- Herança e Polimorfismo
- Interfaces e Classes Abstratas
- Sobrescrita e Sobrecarga de métodos
- Composição e Associação entre objetos
- Boas práticas de nomenclatura e organização de pacotes

---

## 🛠️ Tecnologias

- **Java** (JDK 17+)
- **Maven** (gerenciamento de dependências)
- **IntelliJ IDEA** (IDE utilizada)

---

## ▶️ Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Wendersonjose/praticando-poo-java.git
   ```
2. Abra o projeto no IntelliJ IDEA ou na IDE de sua preferência
3. Navegue até o pacote desejado e execute a classe `Principal` ou `Main`
